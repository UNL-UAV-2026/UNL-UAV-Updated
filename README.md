# UNL UAV Repository

## Preflight Safety Checklist
1. Check where you are flying is legal (watch out for Lincoln Airport, etc.)
2. Are the batteries in good condition and charged? **Make sure you use the NEW batteries not the old ones**
3. Is the ArduPilot Mission Planner firmware updated? 
4. Do you have the harness, spare propellers, connection cables, etc? A fire extinguisher perchance?
5. Clear the area to avoid accidents
